# 🚀 NEXUS AI — Enterprise SaaS Landing Page & Analytics Dashboard

> An ultra-modern, interactive SaaS platform combining a conversion-focused 3D marketing storefront with a dynamic real-time data analytics dashboard.

---

## 🌟 Overview

**NEXUS AI** is a full-suite Web Application designed for next-generation B2B SaaS startups and AI agency platforms. It bridges high-converting product marketing with enterprise-grade data management. Built using cutting-edge UI/UX trends—including dark-mode glassmorphism, 3D visual accents, micro-interactions, and responsive chart components—it offers a seamless dual-mode experience between a landing page and an interactive application workspace.

## ✨ Key Features

### 🌐 Conversion-Optimized SaaS Landing Page
* 💎 **Obsidian Dark Aesthetics:** Deep dark-mode theme (#030712) enhanced with electric purple, cyan glow gradients, and frosted glassmorphism.
* 📦 **3D Micro-Interactions:** Interactive floating glass cards, glowing borders, hover tilt effects, and smooth scroll transitions.
* 💳 **Dynamic Pricing Engine:** Instant Monthly/Yearly subscription billing toggle with automated 20% discount calculations.
* 🎯 **Feature Showcase:** Interactive 3D grid layout highlighting core platform capabilities.

### 📊 Interactive Admin Analytics Dashboard
* 🎛️ **Dual-Mode Architecture:** Instant client-side workspace toggle from landing page to application context.
* 📈 **Real-Time Data Visualization:** Dynamic area charts, interactive telemetry trends, and donut distribution widgets.
* ⚡ **Live Activity Stream:** Real-time log monitoring for active AI agent operations, API latency, and status badges.
* 🛠️ **Interactive Modals & Controls:** Role-based controls, modal triggers for "Deploy Agent", export notifications, and dynamic light/dark mode toggles.

## 🚀 Getting Started (Local Setup)

To run this project locally on your machine:

```bash
# 1. Clone the repository
git clone [https://github.com/YOUR_GITHUB_USERNAME/nexus-saas-dashboard.git](https://github.com/YOUR_GITHUB_USERNAME/nexus-saas-dashboard.git)

# 2. Navigate into the project folder
cd nexus-saas-dashboard

# 3. Install required dependencies
npm install

# 4. Run the development server
npm run dev
